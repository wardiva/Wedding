## Process

1. **Research (one wedding-invitation design agent).** Visit about 6–8 real invitation websites in the container browser, screenshot them at phone size, and write a short summary of the patterns worth borrowing: hero video with names, schedule/timeline layouts, venue cards, dress code. Then make **static mockups** of the new and changed sections, at phone size, in the current site's style.
2. **Client review.** The client approves or adjusts the mockups. **No site code changes before this.**
3. **Build** with a small number of agents, each owning separate files, then QA at phone sizes, then a screenshot review with the client, then deploy to the stable link.
