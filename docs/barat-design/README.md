# Barat invitation: design mockups (for client approval)

These are static mockups at phone size (393×852, shown at 2x). They are **not** the live site, and no site code has changed. They use the site's own fonts (Great Vibes, Cormorant Garamond, Jost, Amiri), its palette (ivory paper, gold, ink brown, sage wash) and its card art (paper texture, gold ornament, botanical sprigs). Each screen also shows the site's music button and "Scroll down" control, so the spacing is realistic.

### How the hero animates (proposed)

1. When the curtains part, the clip fades in and plays once (silent), then holds on the last frame, as the Walima clip does today.
2. The scrim and blur fade in over about 0.8 s.
3. The text rises in order with the site's existing fade-up-and-unblur reveal: eyebrow, then names, then rule, then date, about 150 ms apart, starting about 0.6 s into the clip.
4. With "reduce motion" switched on, the text simply appears.

## Design decisions

- **Legibility first.** Text sits on photos only in the hero, where it is protected by a gradient and blur. Every content section uses solid paper.
- **Three type voices only:** script for names and titles, spaced serif capitals for small labels, and italic serif for sentences. Jost caps are kept for the controls and the hero eyebrow, as on the current site.
- **Gold stays an accent.** It is used for names, ornaments and the primary button. Body text is ink brown for contrast.
- **The arch, sprigs and sage wash** are reused from the existing card art, so the new sections feel native to the site.
- **One idea per screen**, with nothing tilted and no extra navigation bars.
